<h1 align="center">Carousel</h1>
<p align="center">Go implementation of Carousel scheme</p>

> [!IMPORTANT]
> This repository is under construction!

**Carousel** is a Go implementation of Carousel scheme. The structure of this library is heavily influenced by [TFHE-go](https://github.com/sp301415/tfhe-go/).

## References
